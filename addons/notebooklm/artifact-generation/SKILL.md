# Artifact Generation

## Công dụng
Biến tri thức thành deliverable dùng thật cho team hoặc stakeholder.

## MCP Tools
- `studio_create` — tạo artifact (audio, video, slide, report, quiz, flashcards, data_table, mind_map, infographic)
- `export_artifact` — xuất sang Google Docs/Sheets
- `download_artifact` — tải artifact về file
- `studio_status` — kiểm tra trạng thái

## Artifact Types
| Type | Mô tả |
|------|-------|
| `audio` | Podcast deep-dive, brief, critique, debate |
| `video` | Video explainer, brief, cinematic |
| `slide_deck` | Slide thuyết trình |
| `report` | Briefing Doc, Study Guide, Blog Post |
| `quiz` | Câu hỏi trắc nghiệm |
| `flashcards` | Thẻ ghi nhớ |
| `data_table` | Bảng dữ liệu có cấu trúc |
| `mind_map` | Sơ đồ tư duy |
| `infographic` | Đồ họa thông tin |

## Input
- Notebook context + format artifact cần tạo

## Output
- Artifact có thể chia sẻ và tái sử dụng

## Khi nào dùng
- Báo cáo, handoff, test planning, RCA, onboarding
