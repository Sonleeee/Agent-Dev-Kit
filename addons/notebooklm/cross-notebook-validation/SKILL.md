# Cross-Notebook Validation

## Công dụng
So sánh chéo nhiều notebook hoặc nhiều nhóm tài liệu để phát hiện mâu thuẫn.

## MCP Tools
- `cross_notebook_query` — hỏi chéo nhiều notebooks
- `tag` (action=select) — tìm notebooks theo tags
- `notebook_list` — liệt kê notebooks

## Input
- Rule cần đối chiếu, 2 hoặc nhiều nguồn tri thức

## Output
- Điểm khớp, điểm lệch, câu hỏi mở

## Khi nào dùng
- Trước handoff, trước implementation, trước release

## Lưu ý
- Chặn lỗi do team hiểu khác nhau
