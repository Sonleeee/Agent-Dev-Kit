# Meeting-to-Action

## Công dụng
Chuyển biên bản họp thành action items, decisions, blockers và owners theo từng role.

## MCP Tools
- `notebook_query` — hỏi với prompt mẫu trích action items

## Input
- Meeting notes, transcript, workshop summary

## Output
- Action items, owners, blockers, decisions

## Khi nào dùng
- Sau workshop, sau product review, sau technical alignment

## Lưu ý
- Giảm mất thông tin sau họp
- Giúp PM, PO, tech lead chốt action rõ ràng
