# Requirement Extraction

## Công dụng
Trích yêu cầu chức năng, phi chức năng, acceptance criteria, assumptions từ tài liệu.

## MCP Tools
- `notebook_query` — hỏi với prompt mẫu trích yêu cầu

## Input
- PRD, BRD, meeting notes, scope note

## Output
- User stories, acceptance criteria, assumptions, dependencies

## Khi nào dùng
- Discovery, backlog grooming, sprint planning prep

## Lưu ý
- Biến tài liệu thô thành backlog dùng được
