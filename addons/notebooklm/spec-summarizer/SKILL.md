# Spec Summarizer

## Công dụng
Tóm tắt PRD, BRD, API spec, meeting note, ADR theo format có định.

## MCP Tools
- `notebook_query` — hỏi với prompt mẫu tóm tắt
- `notebook_describe` — lấy AI summary tổng thể

## Input
- Tài liệu đã đưa vào notebook + mục tiêu tóm tắt

## Output
- Summary, Key decisions, Open questions, Risks

## Khi nào dùng
- Onboarding, trước refinement, trước sprint planning, trước review tài liệu

## Lưu ý
- Chuẩn hóa cách đọc tài liệu
- Giảm thời gian tổng hợp cho BA, PM, PO, tech lead
