# Structured Research

## Công dụng
Tìm và nghiên cứu tài liệu mới, trích ràng buộc và quyết định kỹ thuật.

## MCP Tools
- `research_start` — tìm sources mới từ web hoặc drive
- `research_status` — theo dõi tiến trình
- `research_import` — import sources tìm được vào notebook
- `pipeline` — chạy chuỗi bước tự động

## Input
- SDK mới, API mới, tài liệu kiến trúc, proposal

## Output
- Constraints, assumptions, risk list, decision brief

## Khi nào dùng
- Tích hợp 3rd-party, nâng version thư viện, đổi kiến trúc

## Lưu ý
- Giảm hallucination khi tích hợp công nghệ mới
