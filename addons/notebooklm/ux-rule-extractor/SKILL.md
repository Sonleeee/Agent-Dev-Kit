# UX Rule Extractor

## Công dụng
Bóc tách luồng người dùng, edge case, validation rule và states UI từ docs và handoff notes.

## MCP Tools
- `notebook_query` — hỏi về flow, states, validation

## Input
- UX docs, mockup notes, design handoff

## Output
- Flow, states, validation rules, edge cases

## Khi nào dùng
- Trước khi code frontend, trước review handoff, trước test UX flow

## Lưu ý
- Giúp designer, dev, BA nói cùng một ngôn ngữ
- Làm rõ các trạng thái mà giao diện cần có
