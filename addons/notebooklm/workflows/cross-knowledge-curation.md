# Knowledge Base Curation

## Skills sử dụng
- Knowledge Ingestion, System Health, Artifact Generation

## MCP Tools
- `notebook_list`, `notebook_rename`, `tag`, `note`, `server_info`

## Các bước thực thi
1. Dùng `notebook_list` rà soát danh sách notebook
2. Dùng `tag` (action=add) nhóm theo domain hoặc project
3. Dùng `notebook_rename` cập nhật title cho nhất quán
4. Dùng `note` (action=create) ghi quy ước dùng notebook
5. Dùng `server_info` kiểm tra trạng thái hệ thống

## Khi nào dùng
- Khi số notebook tăng nhanh, khi team query nhầm ngữ cảnh thường xuyên
