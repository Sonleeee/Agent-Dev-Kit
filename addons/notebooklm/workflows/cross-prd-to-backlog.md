# PRD to Backlog

## Skills sử dụng
- Spec Summarizer, Requirement Extraction, Risk Radar

## MCP Tools
- `notebook_query`

## Các bước thực thi
1. Dùng `notebook_query` tóm tắt tài liệu
2. Dùng `notebook_query` trích user stories và acceptance criteria
3. Xác định assumptions, dependencies, risks
4. Chuyển thành backlog để refinement

## Khi nào dùng
- Đầu initiative, trước sprint planning
