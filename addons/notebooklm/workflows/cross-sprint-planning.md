# Sprint Planning Prep

## Skills sử dụng
- Requirement Extraction, Risk Radar, Cross-Notebook Validation

## MCP Tools
- `notebook_query`, `cross_notebook_query`

## Các bước thực thi
1. Dùng `notebook_query` trích requirement và acceptance criteria
2. Đối chiếu mâu thuẫn giữa docs bằng `cross_notebook_query`
3. Liệt kê blockers và unknowns
4. Chốt danh sách cần làm rõ trước planning

## Khi nào dùng
- Trước mỗi sprint planning
