# 📚 Knowledge Base

> Thư mục này chứa tri thức kỹ thuật tích lũy được qua các projects.
> Tổ chức theo domain/topic.

## Cấu trúc khuyến nghị

```
knowledge/
├── dotnet/        ← .NET patterns, EF Core tips, Clean Arch...
├── react/         ← React patterns, hooks, performance...
├── devops/        ← Docker, CI/CD, deployment...
├── database/      ← PostgreSQL, queries, migrations...
├── ai-agents/     ← Agent workflow learnings, prompt patterns...
└── general/       ← Design patterns, algorithms, tools...
```

## Cách viết

1. **Một file = một concept** (ví dụ: `dotnet/ef-core-migration-tips.md`)
2. Dùng **wikilinks** `[[liên kết]]` để kết nối các concepts
3. Gắn **tags** `#dotnet #performance` để dễ tìm
4. Ghi **nguồn** nếu learn từ bài viết/video cụ thể

> Mục tiêu: Khi gặp vấn đề tương tự, search vault trước rồi hãy Google.
