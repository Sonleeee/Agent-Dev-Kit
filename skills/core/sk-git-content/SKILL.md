# Git content

- Đọc diff và metadata liên quan trước khi tóm tắt thay đổi.
- Dùng convention commit/PR hiện có trong repo nếu có; không bịa scope hoặc kiểm chứng.
- Giữ nội dung ngắn, nêu mục đích, thay đổi và verification evidence khi phù hợp.
- Chỉ tạo/chỉnh file changelog khi user yêu cầu hoặc quy trình repo yêu cầu rõ.
- Hành động `commit`, `push`, `merge` và tạo PR là thao tác tường minh; không suy ra
  quyền đó từ việc soạn nội dung.
