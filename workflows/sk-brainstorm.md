# /sk-brainstorm

**Mục tiêu:** So sánh nhiều approaches/options để chọn hướng tốt nhất.

## Khi nào dùng

- Có nhiều cách giải quyết, chưa biết chọn cách nào
- Cần trade-off analysis
- Cần đánh giá pros/cons trước khi commit approach

## Quy trình

1. **Liệt kê options** (ít nhất 2)
2. **So sánh** theo tiêu chí: complexity, performance, maintainability, risk
3. **Kết luận** — recommend option với lý do
4. **Trình user** quyết định

## Output

Bảng so sánh + recommendation.
